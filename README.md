# Sprint 1 - GitHub Learning Unit

Repositorio creado para practicar Git, GitHub y GitHub Actions.

## Objetivo

Aplicar fundamentos de control de versiones, colaboración y automatización CI/CD.

## Contenido

| Fase | Tema |
|---|---|
| 1 | Git y GitHub |
| 2 | GitHub Actions |
| 3 | CI/CD |

## Comandos básicos usados

```bash
git add .
git commit -m "mensaje"
git push
```

## Evidencias

- Repositorio remoto
- Pull Request
- Issues
- Workflow de GitHub Actions
- Artifact generado
- Secret configurado
- Cache de dependencias
- Deploy simulado
